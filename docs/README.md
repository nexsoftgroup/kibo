# Documentación de Kibo

Todo para instalar Kibo, abrir tu primera sesión y mantenerlo al día. Esta documentación se mantiene al día con cada
versión; las novedades de cada una están en [Releases](https://github.com/nexsoftgroup/kibo/releases).

| | |
|---|---|
| **[Instalar](instalar.md)** | Con un comando en la terminal (Windows, Linux y macOS) o con el instalador de Windows. |
| **[Primeros pasos](primeros-pasos.md)** | Abrir un proyecto, una sesión, la conversación, la cuadrícula y Agent Hub. |
| **[Manual de uso](manual.md)** | La ventana y Agent Hub con cada parte numerada, @nombre y cómo instalar el widget del navegador. |
| **[Todo lo que hace Kibo](funciones.md)** | La guía completa, empezando por Agent Hub: cómo trabajas con cada equipo y cómo orquesta la MAIN. |
| **[Worktree por peer](worktree-por-peer.md)** | Cada peer en su propia copia del repo y en su rama, y tú decides cuándo se integra. *Desde la 1.0.2.* |
| **[Claude Code](cli.md)** | Qué hace falta y qué hace Kibo con él. |
| **[Windows, Linux y macOS](plataformas.md)** | Qué está probado en cada sistema y qué cambia. |
| **[Actualizar](actualizar.md)** | Ver tu versión, enterarte de una nueva y actualizar con un clic. |
| **[Desinstalar](desinstalar.md)** | Conservar tus datos o borrar todo. Tus proyectos no se tocan nunca. |
| **[Preguntas frecuentes](preguntas.md)** | Incluye «Windows protegió mi PC», explicado sin vueltas. |
